# readme if you don't know how to use the careless time logo.
you can see that SVG file named "careless.logo.svg"?
yeah. it mean actual full screen of careless time logo.
we are using the logo at a "self-standardized size"

# how to use with background
first, if you want a background, we use pure black(actual #000000) color.
also, we set the SVG/logo to 60%.

# want no background?
use "careless.logo.svg".

# want some full logo?
don't use what you made.
we already have "careless.full.svg"

# if you want something clear...
use "careless.full.clear.svg". its really clear, like some corp.

# if you want a monochrome-colored logo....
go folder "monochrome/" and choose black or white. there are "careless.logo.svg" and "careless.full.svg" too.

follow our standard, please.
